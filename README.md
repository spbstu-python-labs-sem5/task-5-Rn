# Задача №5: класс точки в Rn с динамической размерностью

Реализуйте функцию-фабрику `make_point_class(n, name=None)`, которая:
1. Создаёт новый класс `PointN` с ровно n атрибутами-координатами: x0, x1, …, x(n-1).
2. Каждый атрибут управляется экземпляром дескриптора `CoordDescriptor`, который:
   - Проверяет, что значение — число (int или float)
   - Вызывает `TypeError` при неверном типе
3. Конструктор нового класса принимает ровно n позиционных аргументов (координат)
4. Класс содержит метод `to_tuple()`, возвращающий координаты как кортеж
5. Добавьте кэширование классов через `functools.lru_cache`, чтобы повторные вызовы
для одного n не создавали класс заново
